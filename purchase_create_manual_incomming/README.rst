This module allows users to manually create an incoming picking directly
from a purchase order, bypassing the standard Odoo procurement flow.
Users can manually generate a receipt (picking) only for purchases that
have not been split, ensuring alignment between stock movements and the
original procurement logic.

Usage
=====

To use this module, you need to:

1. Go to the Purchase Orders menu.
2. Create, or open a confirmed purchase order that has not been split.
3. In the header, click the "Create Manual Receipt" button.
4. A stock picking will be created and linked to the purchase order.

Note: The button will be invisible if the purchase order has been split
using the purchase_split_wizard module.
